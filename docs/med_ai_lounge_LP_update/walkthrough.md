# Walkthrough - 初級編セミナー終了対応

## 実施した変更
初級編セミナーが終了したことに伴い、LP上の表記と機能を更新しました。

### 1. `style.css` の更新
- **終了済みカードのスタイル (`.program-card.ended`)**:
  - カード全体を少しグレーアウト (#f4f4f4)。
  - カード全体に半透明のオーバーレイを追加し、コンテンツを薄く見せる。
  - ヘッダー部分も彩度を落とした色に変更。
- **無効化ボタンのスタイル (`.btn-disabled`)**:
  - ボタンをグレーにし、クリック不可 (`pointer-events: none`) に設定。
  - ホバー効果も無効化。

### 2. `seminar/index.html` (一般公開ページ) の更新
- 初級編のプログラムカードに `ended` クラスを追加し、スタイルを適用。
- 以下の申込ボタンを「終了しました」または「初級編 (終了)」に変更し、リンクを削除して無効化スタイルを適用：
  - プログラム詳細カード内のボタン
  - ページ下部のCTAセクション内のボタン
  - 追従型CTA (Sticky CTA) 内のボタン

### 3. `x7f9k2m/index.html` (LINE限定ページ) の更新
- 一般公開ページと同様に、初級編のプログラムカードと各所の申込ボタンを「終了」状態に変更。

## 確認事項
- 初級編のカードが視覚的に「終了したもの」として認識できること。
- 「初級編」の申込ボタンがクリックできなくなっていること。
- 中級編には影響がないこと。
